Quick reference

How required work becomes agent work

Lifecycle Data
Durable Markdown claims and evidence managed by MDLM.
Process Package
Versioned declarations that define types, rules, work contracts, and Phase behavior.
Phase
A package-declared scope that enables applicable Obligations and Scenarios and declares progression conditions.
Subject
The specific Phase or piece of Lifecycle Data to which a rule applies.
Obligation
A Process Package rule. It selects Subjects and declares what evidence would satisfy the requirement.
Obligation Instance
One Obligation evaluated for one exact subject under one exact Process Package reference.
Loose End
An unsatisfied Obligation Instance reported with its status, blockers, resolver, expected outputs, and waiver rules.
Resolver Scenario
The Scenario named by the Obligation as capable of producing evidence that may satisfy it.
Dispatchable
The Resolver Scenario can safely run now. Its inputs resolve and no declared blocker prevents execution.
Assignment
A temporary work packet reserved against the current repository state. It binds one Scenario, its inputs, its prompt, its output contract, authority needs, and completion checks.
Assignment Response
The harness return for one Assignment. It contains either a complete Scenario Proposal or a typed inability to complete.
Scenario Proposal
Candidate publication content. It becomes Lifecycle Data only after submission validates the complete transaction.
Keep this distinction. A successful submission proves the proposal met the Scenario contract. Reevaluation decides which Obligations are now satisfied and which work is now dispatchable.
