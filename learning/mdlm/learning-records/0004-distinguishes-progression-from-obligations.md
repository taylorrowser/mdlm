# Distinguishes progression from Obligations

The learner correctly explained that Phase progression uses a separate expression rather than relying on Obligation Instance satisfaction. They identified a Process Package defect when progression permits mandatory requirements to remain unsatisfied, and correctly located the Scenario input contract and Obligation binding.

One implementation detail remains to sharpen: the exact bound value is evaluated while preparing work for the authorizing Obligation Instance and is then recorded in the Assignment. It is not a durable field stored inside the Obligation Instance.
