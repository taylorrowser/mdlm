# Define the representative system verification strategy

Read `skills/lifecycle-data.md@1`, `skills/verification-strategy-specification.md@1`,
`skills/verification-independence.md@1`, and `skills/scope-challenge.md@2`.

Define one `VSP` at `level: system` for the supplied exact SYS. Name the smallest
bounded environment-capability profile that can exercise a supported behavior and
one deliberately bad control through a black-box boundary. Do not inspect product
source or unit tests, and do not claim formal SYS verification.

Before proposing Lifecycle Data, apply `skills/author-preflight.md@2`.
