# Review one planning DWP product definition

Read, in order:

1. `skills/contextual-artifact-review.md@2`
2. `skills/scope-challenge.md@2`
3. `skills/review-correction-authority.md@1`

Review exactly one planning DWP against its complete frozen context and the
resolved rubric. Challenge product purpose, stakeholder intent, and scope. Use
the fixed `review_kind: simplification-product-definition` supplied by the
Assignment.

Create one REV with exactly one `reviews` link and one `contextualizes` link. A
passing Review has neither `simplification` nor `blocks`. A failed Review names
the exact DWP as `simplification.target`, links `blocks` to that DWP, records all
current blocking findings, and classifies their `correction_authority`. Add a
`flags` link for each collateral SYS, ASP, ICSP, or DWP finding.
