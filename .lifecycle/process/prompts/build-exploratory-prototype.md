# Build an exploratory prototype

Read, in order:

1. `skills/lifecycle-data.md@1`
2. `skills/prototyping.md@1`
3. `skills/clarification-protocol.md@1`
4. `skills/scope-challenge.md@1`

Build the smallest prototype that discriminates the exact empirical QST. Record
its exact repository reference, supported behavior, deliberately unsupported
behavior, and evidence references in ART. Record the bounded finding as DEC and
link both outputs to the exact question. Do not generalize beyond observed
evidence or treat prototype code as an accepted product implementation.
