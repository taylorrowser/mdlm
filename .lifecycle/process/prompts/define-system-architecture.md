# Define system architecture

Read, in order:

1. `skills/lifecycle-data.md@1`
2. `skills/architecture-specification.md@1`
3. `skills/architecture-elements.md@1`
4. `skills/scope-challenge.md@1`
5. `skills/clarification-protocol.md@1`

Define the smallest architecture context needed to organize the authorized
behavioral slice. Give every element an opaque stable AEL identity, keep aliases
human-facing, and record responsibilities, interactions, constraints, and
nominated risks. Do not use implementation convenience to invent scope.
