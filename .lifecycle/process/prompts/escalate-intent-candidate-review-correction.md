# Escalate an exhausted Phase 0 candidate correction

Read the exact candidate lineage, all supplied failed Reviews and findings, the
current reviewed foundation members, every supplied current passing product-
simplification Review, `skills/lifecycle-data.md@1`, `skills/baseline-model.md@1`,
and `skills/scope-challenge.md@1`. After explicit stakeholder authority, publish
one same-lineage BSL replacement citing every failed Review, preserving every
unaffected member and evidence item, and including every supplied simplification
Review as exact evidence. Publish one exact scope DEC justifying that replacement.
The replacement still requires a fresh independent Review and does not itself
approve, reject, defer, cancel, or terminate the gate.
