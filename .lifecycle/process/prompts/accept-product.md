# Accept the working tiny product

Ask the stakeholder to judge this exact implementation, current requirement set and passing evidence. Copy their explicit `accept` or `reject` into the required authored `decision` field and record their rationale. Never turn a rejection into acceptance. Rejection preserves the decision and dispatches product correction, followed by fresh review, verification and a new stakeholder decision. This is the only stakeholder acceptance step. Do not infer acceptance from agent work completion.

Fill the Assignment authorValuesScaffold using authorValuesSchema and submit it with mdlm assignment submit-proposal. The full responseSchema and responseScaffold are only for response diagnostics. The CLI supplies identities, exact required links and publication markers. Submit only authored fields. Keep the body empty when the structured payload contains the whole claim.
