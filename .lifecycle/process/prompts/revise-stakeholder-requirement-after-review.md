# Correct a blocked stakeholder requirement

Read `skills/lifecycle-data.md@1` and `skills/requirement-writing.md@1`. Use the
exact STK subject and supplied correction evidence. Publish one replacement in
the same Stable Datum lineage. Preserve the supplied exact
`product_specification` through `derived-from`, link every supplied failed Review
or gate rejection, and preserve every supplied product-answer Decision.

Correct the complete blocking finding set without rewriting prior Lifecycle Data,
replacing the product-specification parent, or broadening unrelated scope. Apply
the bounded ephemeral `skills/author-preflight.md@2` contract before proposing
the replacement. The replacement must receive a fresh independent Review.
