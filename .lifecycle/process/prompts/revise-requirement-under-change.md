# Revise the affected requirement first

Use the exact approval and CHG impact to create the next Revision in the affected SYS Stable Datum. Preserve valid source-owned links, add `changed-under` to the exact CHG, and change only approved content. Requirement revision precedes replacement context, Review, baseline, and verification evidence.
