# Freeze one decomposition group candidate

Use the exact reviewed DWP completion to identify its planning Revision, produced
SYS Revisions, architecture Revision, interface Revisions, and both passing
simplification Reviews. Publish one frozen `group-candidate` BSL whose definition
members contain exactly the completion, outputs, architecture, and interfaces,
and whose evidence contains exactly the simplification Reviews. Do not add nearby
or historical Revisions.
