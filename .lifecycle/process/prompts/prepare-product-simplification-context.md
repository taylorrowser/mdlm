# Prepare the Phase 0 product simplification context

Read `skills/lifecycle-data.md@1`, `skills/baseline-model.md@1`, and
`skills/traceability.md@1`. Freeze one `review-context` BSL containing every and
only the supplied exact, individually reviewed MAP, PSP, and STK Revisions. Set
its scope to the exact active Phase reference. Do not include verification,
decomposition, implementation, or unrelated evidence: this boundary exists so
product purpose, stakeholder intent, and scope can be challenged before fan-out.
