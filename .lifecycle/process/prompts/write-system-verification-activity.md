# Write the representative system pilot activity

Read `skills/lifecycle-data.md@1`, `skills/verification-writing.md@1`, and
`skills/verification-independence.md@1`.

Write one `VER(kind: pilot)` from only the exact supplied SYS and VSP. Set its
claim to `kind: pilot`, `scope: verification-design`, and
`formal_evidence_eligible: false`. Define one concrete expected-success activity
and one concrete expected-discrimination activity. This pilots the verification
design; it does not accept the SYS or add formal evidence.

Before proposing Lifecycle Data, apply `skills/author-preflight.md@2`.
