# Prototyping

Start from one exact empirical QST and state what observation would discriminate
its alternatives. Build the smallest throwaway artifact that can produce that
observation. Record an exact repository reference, supported behavior,
intentionally unsupported behavior, and evidence. Capture the bounded finding
as DEC; never promote prototype behavior or an unobserved inference into product
intent.
