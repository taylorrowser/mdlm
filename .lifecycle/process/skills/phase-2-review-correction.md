# Phase 2 Review correction

Create one same-lineage replacement for the exact subject. Address every supplied
primary and collateral Review Finding. Preserve every source-owned exact trace link
provided by the Assignment and all unaffected payload commitments; do not rebind a
dependency merely because nearby evidence changed. Cite every supplied Review
through `corrects-review`.

The replacement requires a fresh exact Review Context and independent Review through
normal reevaluation. When participation is attended, also publish the exact scope DEC
required by the Assignment; it authorizes this Correction but does not replace fresh
Review.
