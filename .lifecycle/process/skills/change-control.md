# Exact change control

- Preserve the immutable pilot RUN and RES that exposed a condition; never reinterpret qualification evidence as product evidence.
- Report the condition in PRB and derive CHG from the exact PRB Revision.
- Bound impact through authored links and name exact requirement, context, Review, baseline, and verification-evidence Revisions.
- Review the impact analysis before recording an exact approval Decision.
- Revise in original-V order: requirements, context, Reviews, baselines, then independent verification evidence.
- Reuse unrelated evidence. Let typed dependency changes and package Policy decide Staleness rather than mutating historical outcomes.
- Close only with an exact Decision citing the CHG and replacement evidence, then revise the PRB in its existing lineage.
