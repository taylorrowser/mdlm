# Pilot assessment

- Count observed exact Review Contexts, completed Reviews, findings, Scenario
  executions, and repository commands; distinguish measurement from estimate.
- Check every claimed reused or Stale item against the exact baseline diff
  explanation. Preserved authorization history is not current reuse by itself.
- Sample Loose Ends for exact subjects, blockers, and actionable resolvers.
- Count candidate, sign-off, and Decision-review ceremony separately.
- Require both supported success and intentionally unsupported rejection before
  claiming verification discrimination.
- Compare proposed, removed, and retained scope explicitly. A simplification
  ceremony with zero removed items is not demonstrated scope reduction.
- Recommend `proceed`, `change`, or `stop`; state limitations and preserve the
  exact frozen evidence context and passing Review in the final Decision.
