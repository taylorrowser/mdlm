# Verification strategy specification

- Define methods, evidence handling, assessment, and independence before bulk activity creation.
- Embed named environment profiles in VSP; do not create a separate capability datum.
- For each profile, state purpose, controllability, observability, services, and timing.
- Require only capabilities needed to make the governed requirements verifiable.
- Preserve exact requirement and strategy provenance.
