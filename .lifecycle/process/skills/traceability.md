# Traceability

- Start from exact input revisions and follow validated outbound links.
- Confirm target type and required identity form for every relationship.
- Compute backlinks; never author them.
- For each parent, account for covered, missing, overlapping, and intentionally
  terminated behavior.
- For each child, identify an authorized parent or applicable decision.
- At baseline freeze, resolve stable targets to exact revisions and retain that map.
- Treat link, target-resolution, allocation, and evidence-target changes as impact,
  not merely textual differences.
- Report uncertainty and graph gaps. Never infer a durable link from proximity or
  naming alone.
