# Wayfinding map

Use MAP as a linked index of the current decision frontier. Keep each decision,
question, prototype pointer, product claim, and stakeholder commitment in its
own typed Lifecycle Datum. Order the frontier by information value rather than
encoding an imperative phase sequence. Remove resolved areas from the active
frontier only after their exact evidence remains reachable through links.
