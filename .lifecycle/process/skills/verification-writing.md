# Verification writing

- Specify externally observable stimulus, observation, threshold, and retained evidence.
- Derive from exact requirements and governing strategy rather than implementation structure.
- For a pilot, include supported-success and intentionally-unsupported discrimination activities.
- Keep pilot claim scope at verification-design suitability.
- Require a new formal run before any requirement-verification claim.
