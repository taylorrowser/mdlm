# Verification run model

- Bind exact ENV, VER, VAI, execution target, runner, and configuration.
- Record expected and invoked activities, timestamps, evidence locations, and execution state.
- Separate completed, aborted, and infrastructure-error execution states.
- Produce one scoped RES per activity outcome.
- Qualification scopes to environment capability; pilot scopes to verification design; formal scopes to requirement.
- Never promote a pilot RES into formal evidence.
