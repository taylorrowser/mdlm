# Prepare the smallest usable prototype

Build the slice needed to answer the experiment's question in a separate Git repository. Record its exact source commit, public command and meaningful exact ICD links. Plan and publish at least one independent VFY activity for the criterion first, with `plan-criterion-verification`; the TRY cannot be published without selecting it through verification links. Their author receives the EXP and public interface contracts, without product implementation source. Product and verification repositories have separate commits.

Run each selected activity, preserve its case results, then record the prototype observation. Prototype source requires no blanket source attribution or formal requirement review. Cut scope when necessary; never report untested criterion behavior as passing. Choose tools that fit the product, including CLI, browser or analysis.
