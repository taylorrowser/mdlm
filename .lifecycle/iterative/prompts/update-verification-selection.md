# Select the current independent activities

Revise the product binding to select exact VFY revisions through verification links. Preserve the source commit, command, repository and production attribution when the product has not changed. An activity revision changes its evidence binding and requires fresh execution; it does not imply a product code change. Include all activities needed for the exact requirement or criterion scope. For an accepted formal product, use the approved-change route instead of this pre-acceptance action.
