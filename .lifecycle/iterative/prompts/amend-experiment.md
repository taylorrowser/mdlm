# Amend an untried experiment

Read the exact `subject` brief. Revise that same EXP lineage before its first
TRY when its criterion, provisional approach or necessary public interfaces
need adjustment. Preserve useful intent and explain the amendment in the body.
Keep generated `responds-to` links to `origin` and `compares-to` links to
`baseline`; either input may be empty.

Select the complete necessary public contract set with optional `uses-interface`
links to exact ICD revisions. Retain unchanged selections and adopt changed ICDs
explicitly. Record a missing ICD first with `record-interface`. Leave the set
empty when the criterion needs no interface agreement. Criteria and interface
choices remain provisional; this action creates no requirements or acceptance.

Export `mdlm verification context <new-EXP-revision> --json` for independent
verification authoring. The new EXP needs verification bound to that exact
context even when criterion wording is unchanged. Earlier plans and evidence
retain their old meaning. After a TRY exists, use the normal observation or
stakeholder-feedback revision route.
